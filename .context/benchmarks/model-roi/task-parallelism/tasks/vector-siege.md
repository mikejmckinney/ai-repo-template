# Vector Siege Phase 0A Contract

## Candidate-Safe Assignment

Build Vector Siege as the staged TypeScript, Vite, Phaser 4 browser arena shooter
defined by issue #545. Candidate implementation starts only in an approved later
phase from one frozen minimal scaffold and one frozen standardized asset bundle.

## Phase 0A Scope

Phase 0A validates only:

- tracked campaign freeze state;
- deterministic placeholder MP3, WAV, WebP, palette, atlas, and manifest files;
- pinned Draft 2020-12 schema validation;
- provider-credential removal and bounded no-network/no-child-process controls;
- the explicit `phase_0b: blocked` state.

No candidate prompt, runtime adapter, model invocation, game implementation,
deployment, provider mutation, polished media generation, or policy amendment is
part of Phase 0A.

## Phase 0B Boundary

The first feasibility campaign remains five matched randomized Stage 1
repetitions each for Arms A and B using Codex `gpt-5.6-luna` at `max` effort.
Those runs require a separate explicit maintainer approval after Phase 0A passes.
